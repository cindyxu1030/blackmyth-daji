# 黑神话 · 妲己

Fable 5 能力演示游戏：你是九尾狐妲己（人形，黑金汉服+发光九尾），在月夜朱雀台废墟迎战三阶段 Boss 二郎神杨戬（暗蓝层叠金边甲）。
浏览器 3D 动作游戏（Three.js r147，全程序化建模，零外部素材依赖）。

v2 电影感升级：低机位过肩相机、手搓 HDR 后期管线（真 bloom/胶片颗粒/调色/暗角，`js/config.js` 里 `POST: false` 一键关）、PMREM 环境反射、远山剪影/地面流雾/漫天飘灰/月光柱。

## 怎么玩

**方式一（推荐，全部画面生效）**：本目录下起本地服务器

```
python -m http.server 8123
```

打开 http://localhost:8123

**方式二（双击即玩）**：直接双击 `index.html`。游戏完整可玩，
唯一区别：浏览器安全策略禁止 file:// 下的 WebGL 纹理，天空盒/地面贴图会自动回退为程序化版本，UI 图（标题/结算/头像/名片）不受影响。

> 开打前切换到英文输入法（ENG），否则 J/K/L 会被输入法吃掉。

## 操作

| 键 | 招式 |
|---|---|
| WASD | 移动（相机相对） |
| J | 狐爪连击 ×3 |
| K | 九尾横扫（重击，耗体力 25） |
| 空格 | 影遁翻滚（无敌帧 0.3s，耗体力 30） |
| F | 饮·狐露（回血 45，每局 3 瓶，饮用 0.9s 不能动） |
| L | 魅惑·定身 Boss 3 秒（CD 20s，三阶段减半） |
| ; | 九尾分身（妖力槽满时召唤 3 狐影围攻 8 秒） |
| R / 回车 / 点击 | 结算画面重开（战斗中按 R 也可直接重开） |

妖力槽：打中 Boss / 受击都会积攒。金光预警 = 可躲的近战，红光预警 = 大招（突刺/裂地斩/激光）。

## Boss 阶段

1. **三尖两刃·连斩** —— 三连斩 / 横扫千军 / 贯虹突刺 / 裂地斩
2. **天眼·焚世**（血量 66%）—— 旋转激光扫射 + 追踪光束，贴近 Boss 身边可躲进激光内圈
3. **真君之怒**（血量 33%）—— 狂暴加速 + 哮天犬入场（扑咬后有 1.2s 硬直惩罚窗口）

## 演示保险（直播救场）

- `1` / `2`：直接跳到第二 / 第三阶段
- `0`：无敌开关（左上角显示「天命加身」）
- 切出窗口自动暂停，按任意键继续
- 任何 JS 异常只冻结 AI 不白屏

## 自测模式（CI/验证用）

`http://localhost:8123/?selftest=1` —— 自动跑完：三阶段切换 → 定身+分身 → 胜利 → 重开 → 败北，
结果写入控制台 `[SELFTEST]` 与页面左下角 JSON（pass/errors/drawCalls）。

## 文件结构

- `js/config.js` —— 所有数值（伤害/CD/血量/配色）集中可调
- `js/player.js` `js/boss.js` `js/clone.js` —— 妲己 / 杨戬+哮天犬 / 分身
- `js/world.js` `js/vfx.js` —— 竞技场 / 粒子+预警贴花+震屏
- `js/main.js` —— 状态机、主循环、锁定相机、伤害结算单一入口
- 锁定 Three.js r147 UMD（`vendor/`），经典脚本加载，file:// 兼容
